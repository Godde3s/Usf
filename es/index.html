Proyectos Destacados · Open Source

Construidos en público,
usados en producción.

Una selección de repositorios de github.com/Godde3s — puentes de API de IA gratuitas, routers de modelos, stacks de agentes, paneles proxy y herramientas de seguridad. Cada repo es real, está documentado y funciona hoy.

🧠

glm-free-api

Go

Una API completa compatible con OpenAI y Anthropic para GLM en un solo archivo Go — sin navegador, sin Chrome headless, sin servidor de cuentas. Pool de cuentas integrado, respuestas en streaming y despliegue de un comando donde quiera que corra Go.

GitHub
🧭

omnirouter

Go

Un router inteligente para todos los modelos de IA: GLM, Qwen, DeepSeek y APIs propias detrás de un endpoint unificado con balanceo round-robin, failover automático y cuotas por ruta. Tu app habla un protocolo; el router se encarga del resto.

GitHub
👻

GhostBrain

Python

Resucita una cuenta gratuita de Gemini como una API real compatible con OpenAI y Anthropic — con vinculación segura de sesión, pools multi-cuenta, streaming SSE y persistencia. El puente que convierte 'una página de chat' en infraestructura.

GitHub
🤖

hermes-stack

Python

Hermes Agent + 9Router + OmniRouter empaquetados en un solo Space gratuito de Hugging Face — un cerebro de IA auto-alojado en la nube a coste cero. Agentes, enrutamiento de modelos y automatizaciones, desplegables en minutos.

GitHub
🛰️

Usf-panel

Python

Gestor premium de túneles VLESS y suscripciones: panel proxy multiusuario y multiprotocolo con sincronización de configs Clash / v2ray / sing-box, desplegable en un comando en Hugging Face, Railway, Render, Fly.io o Koyeb.

GitHub
⚡

usf-edge

JavaScript

Panel de gestión proxy de nueva generación que corre enteramente en Cloudflare Workers — cero servidores, cero arranques en frío, 317+ PoPs. Estado respaldado en KV, panel admin con token+2FA y endpoints de suscripción servidos desde el edge.

GitHub
🔌

HardwarePT

C

Escáner de puertos de hardware de bajo nivel escrito en C puro — cerca del metal, sin dependencias. Hecho para entender qué ocurre realmente en el cable y en la placa.

GitHub
🛡️

explorer

Python

Analizador estático de seguridad que caza patrones vulnerables y rutas de código inseguras en repositorios — la misma disciplina que aplico al auditar mi propio código generado por agentes antes de publicarlo.

GitHub

🔛

OpenCode

Agente de codificación open-source en terminal — mi opción para programación en pareja rápida y agnóstica al modelo en cualquier repo. Cambiable de proveedor a mitad de tarea, perfecto para enrutar a través de mi propio omnirouter.

⚡

Codex

El agente de código de OpenAI para ejecución paralela de tareas — desde arreglos rápidos hasta refactors de larga duración. Ideal cuando un cambio se ramifica en muchos archivos manejables en sandboxes aisladas.

🎩

Claude Code

El CLI agéntico de Anthropic — planificación multi-paso, uso de herramientas y ediciones en todo el codebase con precisión quirúrgica. Planifica como un ingeniero senior y ejecuta como un equipo entero; este sitio es una de sus obras.

🤖

Hermes Agent

Mi propia infraestructura de agentes (github.com/Godde3s/hermes-stack) — un cerebro de IA auto-alojado que enruta modelos, ejecuta automatizaciones y mantiene a los demás agentes alimentados con el modelo correcto en el momento correcto.
