التخصصات الأساسية · ماذا أفعل

مهندس واحد،
كل طبقات المنظومة.

من المتحكمات الصناعية إلى وكلاء الذكاء الاصطناعي — أُصمم وأنظم وأسلّم أنظمة كاملة، لا مجرد شيفرة. أربعة تخصصات وعقلية واحدة: افهم المشكلة بعمق، ثم ابنِ أبسط حل يعالجها بالكامل.

🌐

فول-ستاك ويب وتطبيقات

أنظمة متعددة المنصات محورها الويب، من البكسل إلى الإنتاج. واجهات أمامية بـ React و Vue و Angular و Next.js؛ خلفيات بـ Node.js و Laravel و .NET و Django و FastAPI و Go؛ وطبقات بيانات على PostgreSQL و MySQL و MongoDB و Redis — تُسلّم كلها كمنتج واحد متماسك مع Docker و CI/CD.

🤖

الذكاء الاصطناعي والأنظمة التوليدية

معالجة اللغة الطبيعية والذكاء الاصطناعي التوليدي في إنتاج حقيقي لا عروض تجريبية: خطوط LangChain وقواعد معرفة RAG وجسور API للنماذج اللغوية وتنسيق متعدد الوكلاء. أربط نماذج مثل GLM و Qwen و DeepSeek و Gemini بخدمات متوافقة مع OpenAI تبني عليها البرمجيات الأخرى.

🏭

PLC والأتمتة الصناعية

أتمتة والتحكم بالعمليات بلغة مخطط السلم (LD) والنص المهيكل (ST) وفق معيار IEC 61131-3 — من منطق الحساسات والمشغلات إلى برامج تحكم جاهزة للـ HMI تُبقي الآلات الحقيقية تعمل بأمان وتوقع وبشكل دائم.

🔬

البحث والأمن

بحث تطبيقي في الأمن السيبراني وعلم النفس المعرفي والهندسة الاجتماعية — إضافة إلى التاريخ والمنطق والفلسفة. فهم كيف تتصرف الأنظمة والشبكات والبشر فعلًا هو ما يمكّنني من تصميم برمجيات تنجو عند ملامسة الواقع.

البرمجة الوكيلية · قوتي الخارقة

أنا لا أستخدم الذكاء الاصطناعي فحسب.
أقود فرقًا من الوكلاء.

أدواتي اليومية هي OpenCode و Codex و Claude Code — منسّقة عبر حزمة هيرميس أجنت الخاصة بي. أسلّم برمجيات إنتاجية بتوجيه وكلاء برمجة مستقلين عبر المواصفات وإعادة الهيكلة متعددة الملفات والاختبارات والمراجعات والنشر. هذه الصفحة نفسها بُنيت بهذه الطريقة.

🔛

OpenCode

وكيل برمجة مفتوح المصدر في الطرفية — خياري الأول للبرمجة الثنائية السريعة والمستقلة عن النموذج في أي مستودع. قابل لتبديل المزود في منتصف المهمة، ما يجعله مثاليًا للتوجيه عبر omnirouter الخاص بي.

⚡

Codex

وكيل البرمجة من OpenAI للتنفيذ الموازي للمهام — من الإصلاحات السريعة إلى إعادة الهيكلة الطويلة. مثالي حين يتفرع تغيير عبر ملفات كثيرة يمكن معالجتها في بيئات معزولة.

🎩

Claude Code

واجهة Anthropic الوكيلية — تخطيط متعدد الخطوات واستخدام أدوات وتحرير يمتد لكامل الشيفرة بدقة جراحية. يخطط كمهندس أول وينفذ كفريق كامل؛ وهذا الموقع أحد أعماله.

🤖

Hermes Agent

بنيتي التحتية الخاصة بالوكلاء (github.com/Godde3s/hermes-stack) — عقل ذكاء اصطناعي ذاتي الاستضافة يوجّه النماذج ويشغّل الأتمتة ويغذي بقية الوكلاء بالنموذج الصحيح في اللحظة الصحيحة.
